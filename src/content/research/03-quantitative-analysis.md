A picture alone is hard to compare between patients, scanners or visits. A common summary
number is the **ventilation defect percentage (VDP)** — the share of the lung that does not
receive inhaled gas. How that number is calculated, however, can change the result.

I develop and benchmark analysis methods for this, such as **mean-anchored generalized
linear binning**, which I compared against established methods for quantifying ¹²⁹Xe
ventilation defect percentage. I have also contributed to open-source analysis software
with a graphical interface for hyperpolarized ¹²⁹Xe MRI, and to studies evaluating deep
learning for removing noise from xenon images. I use standard neuro- and medical-imaging
tools (FSL, ANTs, ITK-SNAP, SPM) alongside my own code in Python and MATLAB.
